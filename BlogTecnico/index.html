Actualizacion Critica o Parches del Sistema Operativo

Descripcion del Problema

Microsoft publica un parche urgente para .NET y Linux (CVE-2026-111497)

Microsoft ha lanzado una actualización de seguridad urgente para corregir vulnerabilidades graves que afectan a .NET (identificada como CVE-2026-111497) y a los sistemas de distribución de archivos en Linux (CVE-2026-114148).

Detalles de las vulnerabilidades

CVE-2026-111497: Permite lectura/modificación de memoria sin autenticación, afectando a aplicaciones que usan descompresión Brotli (HttpClient, ASP.NET Core y System.IO.Compression).

CVE-2026-114148: Fallo en metadatos de distribución para Linux que posibilita la elevación de privilegios a nivel local.

Solucion Aplicada

Recomendaciones de Microsoft según el tipo de aplicación

Entorno en el sistema: Actualizar .NET y reiniciar el servicio.

Aplicaciones autónomas: Recompilar y publicar de nuevo.

Contenedores: Reconstruir y desplegar imágenes actualizadas.

Desde código fuente: Descargar artefactos actualizados y reconstruir paquetes.
