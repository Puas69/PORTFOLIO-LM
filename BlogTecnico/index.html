Actualizacion Critica o Parches del Sistema Operativo

Descripcion del Problema

Microsoft publica un parche urgente para .NET y Linux (CVE-2026-111497)

Microsoft ha lanzado una actualización de seguridad urgente para corregir vulnerabilidades graves que afectan a .NET (identificada como CVE-2026-111497) y a los sistemas de distribución de archivos en Linux (CVE-2026-114148).

Detalles de las vulnerabilidades

CVE-2026-111497: Permite lectura/modificación de memoria sin autenticación, afectando a aplicaciones que usan descompresión Brotli (HttpClient, ASP.NET Core y System.IO.Compression).

CVE-2026-114148: Fallo en metadatos de distribución para Linux que posibilita la elevación de privilegios a nivel local.

Solucion Aplicada

Recomendaciones de Microsoft según el tipo de aplicación

Entorno en el sistema: Actualizar .NET y reiniciar el servicio.

Aplicaciones autónomas: Recompilar y publicar de nuevo.

Contenedores: Reconstruir y desplegar imágenes actualizadas.

Desde código fuente: Descargar artefactos actualizados y reconstruir paquetes.

Nuevo Servicio Docker

Descripcion de Docker

Docker es una plataforma de software que permite empaquetar, distribuir y ejecutar aplicaciones dentro de contenedores ligeros e independientes.

Qué es un contenedor?

Es un paquete ejecutable que incluye todo lo necesario para que una aplicación funcione: código, tiempo de ejecución (runtime), bibliotecas y variables de entorno.

Funciona de manera aislada sobre el sistema operativo del servidor, lo que consume menos recursos que una máquina virtual tradicional.

Para que se sirve

Portabilidad: Garantiza que la aplicación se comporte exactamente igual en tu ordenador de desarrollo, en el servidor de pruebas o en la nube.

Rapidez: Los contenedores arrancan en segundos porque comparten el núcleo (kernel) del sistema operativo.

Aislamiento: Evita conflictos entre dependencias o versiones de software de diferentes proyectos

Buena Practica Para Backups

La Regla de Oro: La estrategia 3-2-1

3 copias en total: Conserva tus datos originales y al menos dos copias adicionales.

2 soportes diferentes: Guarda las copias en dos tipos de medios distintos (por ejemplo, disco duro externo y la nube).

1 copia fuera de sitio: Almacena al menos una copia en una ubicación física o geográfica diferente (como un servicio en la nube o en casa de un familiar) para evitar que un incendio o inundación destruya todo.

Prácticas esenciales de gestión

Automatiza las copias: Programa procesos automáticos para no depender de la memoria o del trabajo manual.

Define la frecuencia adecuada: Realiza respaldos diarios si tus datos cambian constantemente (como bases de datos), o semanales/mensuales si la información es más estática.

Prueba las restauraciones: Comprueba de forma periódica que los archivos se puedan recuperar; un backup que no se puede restaurar es inútil.

Utiliza copias inmutables o cifradas: Protege los respaldos contra el ransomware (secuestro de datos) mediante tecnologías que impidan modificar o borrar los archivos durante un tiempo determinado.
