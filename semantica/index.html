Conceptos y Tipos de Bases de Datos

Bases de Datos Relacionales (RDBMS)

Las bases de datos relacionales organizan la información en tablas compuestas por filas (registros) y columnas (campos). Se basan en el modelo relacional y utilizan el lenguaje SQL para realizar consultas y gestionar los datos de manera estructurada.

Ejemplos de sistemas gestores relacionales populares son MySQL, PostgreSQL y Oracle

Bases de Datos No Relacionales (NOSQL)

Las bases de datos NoSQL están diseñadas para gestionar grandes volúmenes de datos no estructurados o semiestructurados. A diferencia de las relacionales, no requiren un esquema rígido y permiten escalabilidad horizontal.

Existen distintos tipos segun el modelo de almacenamiento: orientadas a documentos, clave-valor, columnas o grafos. Un ejemplo representativo es Mongo DB

Estructuras de una Base de Datos Relacional

  • Tablas (Entidades): Estructuras donde se organizan los datos.
  • Campos (Atributos): Columnas que definen la tipología de información.
  • Registros (Tuplas): Filas que contienen cada instancia concreta de datos.
  • Claves primarias (Primary Keys): Identificadores únicos de cada registro

Relaciones entre Tablas

  • 1:1 (Uno a Uno): Un registro de la Tabla A se relaciona con un único registro de la Tabla B, y viceversa.
  • Relacion 1:N (Uno a Muchos): Un registro de la Tabla A puede estar asociado con varios registros de la Tabla B, pero cada registro de la Tabla B pertenece a uno solo de la Tabla A.
  • Relacion N:M (Muchos a Muchos): Varios registros de la Tabla A pueden relacionarse con varios registros de la Tabla B.
  • Claves Foraneas: es una columna o grupo de columnas en una tabla que apunta a la clave primaria de otra tabla para enlazar ambas y mantener la coherencia de los datos.

Recursos

Glosario de Terminos

SQL(Lenguaje de Consulta Estructurada): es un lenguaje de programación estandarizado que se usa para administrar, consultar y manipular bases de datos relacionales.

SGBD: es un software que sirve como intermediario entre los usuarios, las aplicaciones y una base de datos para permitir el almacenamiento, la modificación y la recuperación de información de forma segura.

Normalización: La normalización de bases de datos es el proceso de organizar y estructurar los datos en tablas para reducir la repetición y proteger la integridad de la información.
